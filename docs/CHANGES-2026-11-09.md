## Shut down when idle

How it works: a small script on the host (`~/.vmc/shutdown/watch.sh`) checks every 30 s. The host counts as busy if any Claude or Codex transcript was written inside the idle window, if the load is at or above 0.8, or if a build or test tool is running. After the idle window it runs Windows `shutdown.exe /s /t <seconds>` through WSL. Windows shows a countdown on the PC, and `shutdown /a` there cancels it. Turning the toggle off kills the watcher and runs `shutdown /a`.

Safety choices:
- The toggle is **disabled until the host has a saved MAC address**, because a powered-off PC can't be woken from here without Wake-on-LAN.
- It was never armed on the PC. I ran the real script on the PC only with a fake command that touches a file, in a temp folder.
- It only targets Windows (`/mnt/c/Windows/System32/shutdown.exe`), so it does nothing useful on the Oracle VM.
- Limits: a long task that writes nothing, uses little CPU and runs no known build tool would look idle. Raise the idle window for those nights.

## Task boards (Mac only)

- Each task is a folder `.context/<KEY>/` inside a worktree, with a `TASKS.md`.
- The Tasks tab scans the repos listed in Settings → Repositories, merges folders with the same key across worktrees, and gives you search, a checklist you can click, and a text editor that saves as you type. It picks up changes an agent makes within about 5 seconds.
- The menu bar icon shows the number of open items, and the popover lists the tasks with open items.
- Creating a board: use the form at the bottom of the Tasks tab. The key defaults from the branch name (`issue-705`, `ABC-123`, or the branch name).
- Read and write are limited to `<worktree>/.context/<KEY>/TASKS.md` of worktrees found in the last scan.
- Not built yet: screenshots, the reference board, before/after, the PC, Jira/GitHub/GitLab, menu bar variants.
