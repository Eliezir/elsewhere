What it does

Everything about your VM, in one calm window.

Elsewhere talks to your VM over the SSH connection you already have. No agent to install and nothing exposed to the internet.

Send and sync

Move work to the VM and back, and see when a copy is stale.

Send a worktree with its branch, unsaved changes and Claude sessions. When the Mac and VM copies drift apart, Elsewhere shows which side is ahead and offers a one-click sync in the safe direction. It only fast-forwards, so nothing is overwritten.

  • Unsaved work is committed as a WIP commit first
  • Refuses to guess when both sides changed
  • Claude sessions copied with their paths rewritten

Ports

Every dev server on the VM, forwarded to your Mac on its own.

Elsewhere watches what is listening on the VM, groups it by project and branch, and opens a tunnel for each one in the background. If a port is already taken on your Mac it picks another and tells you which link to use. Pin a number you want to keep.

  • Open, copy the link, pin a port, stop forwarding
  • Kill a server on the VM, with a confirm and a force step
  • System services are listed read only

Keep it running

Close the laptop. The agent keeps going.

Claude runs on the VM inside a named tmux session, so it keeps working when your Mac sleeps. Resume any copied conversation from a button, and reattach later from any device that can SSH in. Open a worktree in Claude Desktop over SSH with a catch-up prompt already filled in.

  • Resume a specific conversation, not just the latest
  • Reattach from a phone or another PC over Tailscale
  • Open in Claude Desktop with the folder path copied

Clean up safely

Delete the right copy, with a deliberate press.

When a worktree is on both machines you choose which copy to delete: the Mac, the VM or both. Git refuses if there are uncommitted changes, and forcing it takes a press and hold, not a stray click. See what each project costs on the VM before you decide.

  • Mac copy, VM copy or both, in one step
  • Hold to delete anyway when changes would be lost
  • Disk use by project and by folder

How it works

From your laptop to the VM in four steps.

Connect

Enter your VM's Tailscale host name and user in Settings.

Send

Pick a worktree and send it. Elsewhere pushes the branch and copies the Claude sessions.

Work

Open it in T3 Code or a terminal on the VM. Ports forward on their own.

Bring back

Pull the result home with a fast-forward only merge. Nothing is overwritten.
