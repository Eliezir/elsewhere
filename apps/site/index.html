What it does

Everything about your VM, in one calm window.

Elsewhere talks to your VM over the SSH connection you already have. No agent to install and nothing exposed to the internet.

⇄

Send and bring back

Move a worktree to the VM with its branch, uncommitted work and Claude sessions. Bring it back whenever you like. It is always a copy first.

⌁

Ports that just work

See every dev server listening on the VM and forward each project's ports to this Mac automatically, with a clear note when a port is already taken.

◧

Storage you can read

Disk use by project and by folder, so you know what is worth cleaning up before the VM fills up.

✦

Claude usage

Your 5-hour and weekly limits, reset timers and how much capacity is likely to go unused.

❖

Every worktree, labelled

See where each one came from, whether Conductor, T3 Code, a Claude agent or by hand, and open it in the right tool.

◐

Tailscale built in

Connection state, approval prompts and reconnecting without leaving the app. Sits in the menu bar when you want it quiet.

How it works

From your laptop to the VM in four steps.

Connect

Enter your VM's Tailscale host name and user in Settings.

Send

Pick a worktree and send it. Elsewhere pushes the branch and copies the Claude sessions.

Work

Open it in T3 Code or a terminal on the VM. Ports forward on their own.

Bring back

Pull the result home with a fast-forward only merge. Nothing is overwritten.

Ready to work elsewhere?

The builds are not signed yet. On macOS, right-click the app and choose Open the first time. On Windows, choose More info, then Run anyway.
