What it does

Everything about reaching your PC, in one calm window.

Elsewhere talks to your machine over the SSH and Tailscale connection you already have. No agent to install and nothing exposed to the internet.

Power

Wake it, sleep it, shut it down, from anywhere in the house.

Send a Wake-on-LAN packet when the PC is asleep or off, and put it to sleep, shut it down or restart it when you are done. Every action that takes the machine away asks for a deliberate press and hold, so a stray click never ends a session.

  • Wake, Sleep, Shut down and Restart in one card
  • Live connection status, so the buttons match the PC's real state
  • Optional shut down or sleep when the PC has been idle for a while

Gaming mode

Dev mode for work, gaming mode for the rest of the night.

One switch stops the development environment so the PC is all yours for games, then it returns to dev mode on its own the next time the machine starts. Elsewhere waits if something is still busy, so it never pulls the floor from under a running job.

  • Hold to start, so it is never an accident
  • Skips the switch while work is running
  • Back in dev mode after every boot

Keyboard and mouse

One keyboard, one mouse, two computers.

Elsewhere drives Lan Mouse on both machines, so your Mac's keyboard and mouse can move onto the PC's screen. Open it on the PC from the app or the menu bar, borrow it for 15 minutes, and release it with a shortcut when you want the cursor back.

  • Open and close Lan Mouse on the PC remotely
  • Use for 15 minutes, then hand control back
  • Set up from the app, with a release shortcut

In the background

Ports forward themselves, and you hear about it when something needs you.

Elsewhere watches what is listening on the PC, groups it by project and branch, and opens a tunnel for each dev server without a settings screen to manage. If a port is taken on your Mac it picks another one. Native notifications tell you when the PC goes offline, comes back, or a disk is nearly full.

  • Nothing to configure: forwards appear and disappear on their own
  • Notifications for offline, back online, low disk and port conflicts
  • Menu bar popover with health, power and quick actions

Worktrees, labelled

Send a project to the PC with its branch, unsaved changes and Claude sessions, and see where each worktree came from. Sync only fast-forwards, so nothing is overwritten.

Storage at a glance

Claude Code mods

The workbench mod brings the Ports pane, with Kill, and a status line into Claude Code and the Desktop Code tab. Install it from this repository.

⇄

More than one machine

Add a second host, such as a VM, and switch which one is primary. Each machine can be turned on or off from Settings.

◧

Private by design

No servers of ours, no account, no analytics. It uses your own SSH and Tailscale, and never opens a public port.

⇪

macOS and Windows

A native Electron app for Apple Silicon and Intel Macs, and a preview build for Windows 10 and 11. Lan Mouse control is for macOS.

How it works

From your laptop to your PC in four steps.

Connect

Enter the PC's Tailscale host name and user in Settings. Add its MAC address to enable Wake.

Check

The Overview and the menu bar show if the PC is online, how busy it is and how much disk is left.

Control

Wake it, switch to gaming mode, borrow the keyboard and mouse, or send it to sleep.

Forget it

Ports forward on their own and notifications speak up only when something needs you.
